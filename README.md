# DSA in C

A simple collection of common data structures and basic APIs written in C.

This project is built for learning and practice. The goal is to keep the code easy to read, easy to understand, and useful for real C programming.

## Included

- Arrays
- Linked List
- Stack
- Queue
- Trees
- Graphs
- Hash Table
- Heap
- Basic utility functions and APIs

## Purpose

The idea is to understand how data structures work, how they are built, and how to use them in small projects.

This is not a large library or framework. It is a clean, beginner-friendly set of implementations that are easy to explore and build on.

## Getting started

Compile the project with a C compiler and run the example program.

```bash
gcc main.c -o dsa
./dsa
```

If you want to add new data structures or improve the existing ones, feel free to contribute.
